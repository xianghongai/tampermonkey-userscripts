# Copy Anyway

有的网页禁止选择文字、禁止复制，或者在复制的内容后面追加版权声明。这个脚本让这些页面恢复正常的选择与复制。

- 生效页面：内置的常见网站，例如知乎、CSDN、掘金、简书、豆瓣、哔哩哔哩专栏、极客时间、360doc；其他网站可以手动开启
- 可以正常拖选文字，选中时有高亮
- 可以用快捷键、右键菜单复制，复制到的是原文，不附带网站追加的内容

## 在其他网站开启

在需要的网站上点击 Tampermonkey 图标，选择本脚本菜单里的「在 当前域名 上启用」，立即生效；再次点击同一菜单即可停用。

开启后，该网站自己的右键菜单、「复制」按钮等功能可能失效，只建议在禁止复制的网站上开启。
