# No-Translate Zones

翻译外文网页时，代码会被一并翻译，变得无法使用。这个脚本把代码块，以及按规则指定的内容标记为「不翻译」，谷歌翻译、浏览器的整页翻译等遵循该标记的翻译工具都会保留原文。

- 生效页面：所有网站
- 所有网站上的代码块、行内代码、按键提示和程序输出都不翻译
- 已为部分网站内置额外规则，例如 Node.js 文档、Wolfram Alpha
- 页面后续加载的内容同样生效，不需要手动触发

## 自定义规则

可以为任意网站补充不翻译的内容，脚本更新后自定义规则仍然保留。

1. 打开 Tampermonkey 管理面板，进入本脚本的编辑页，切换到「存储」页。看不到该页时，先在 Tampermonkey 设置里把「配置模式」改为「高级」。
2. 编辑 `rules` 的值并保存。写法如下，键是生效范围，值是要保持原文的元素的 CSS 选择器：

```json
{
  "*": [".math"],
  "example.com": [".api-name"],
  "example.com/docs": ["table td:first-child"]
}
```

- `*`：所有网站
- `example.com`：该域名及其子域名
- `example.com/docs`：该域名下 `/docs` 及其下级页面
