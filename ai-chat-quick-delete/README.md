# AI Chat Quick Delete

AI 对话用得越久，左侧列表里堆的对话越多，删除要点「更多」、找删除、再确认，一次删一个很麻烦。这个脚本在每个对话右边加一个删除图标，点一下就删掉。

- 生效页面：ChatGPT、Claude、Gemini、DeepSeek、通义千问（chat.qwen.ai）、Grok 的对话页
- 鼠标移到对话上时，在「更多」按钮左边出现垃圾桶图标
- 点击图标即删除该对话，不用再点菜单和确认框
- 删除后无法恢复，请确认后再点
- 可在 Tampermonkey 菜单中切换「自动确认删除」，默认开启；关闭后点击图标只会弹出网站自带的确认框，由你自己确认
- Grok 本身点了删除就直接删除、没有确认框，所以在 Grok 上「自动确认删除」开关不起作用，点击图标总是直接删除
