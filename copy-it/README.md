# Copy it 🚀

按住 Alt 点击网页上的任意元素，即可复制其中的文字，不用再拖选；还能直接复制成常用的变量命名风格。

- 生效页面：所有网站，`github.dev` 与 `vscode.dev` 除外（它们用 Alt+点击添加多个光标）
- 复制成功后，指针旁会短暂显示复制的内容

## 操作

| 操作 | 复制的内容 |
| :--- | :--- |
| Alt + 点击 | 元素的文字 |
| Alt + Shift + 点击 | 转为 kebab-case |
| Alt + Ctrl + 点击（macOS 为 Option + Command + 点击） | 转为 snake_case |
| 右 Alt + 点击 | 转为 camelCase |
| 右 Alt + Shift + 点击 | 转为 PascalCase |
| Alt + Shift + Ctrl + 点击（macOS 为 Option + Shift + Command + 点击） | 元素的 title 提示文字 |

- 输入框复制已填写的内容，未填写时复制占位提示；密码框不复制明文。
- 下拉框复制选中项的文字。
- 图标、图片这类没有文字的元素，复制其无障碍名称或替代文字。
