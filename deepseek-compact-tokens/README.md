# DeepSeek: Compact Tokens

把 DeepSeek 平台用量页面上的 Token 数量显示为 K/M/B 缩写，方便一眼看出量级。

## 生效页面

- https://platform.deepseek.com/usage

## 功能

- 页面上的 Tokens 数量会转换为「数值 + 单位」，例如 `95,773,316` 显示为 `95.77M`。
- 工具栏右侧新增刷新按钮，点击后重新加载页面以获取最新用量。
- 鼠标悬停在数值上，可查看精确数值及中文语境下的换算，例如 `95,773,316（9,577万）`。
- 鼠标悬停在单位上，可查看 K/M/B 对应的中文单位，以及千、万、十万、百万、千万、亿、十亿、百亿、千亿的常用对照。
