# No AD

按规则隐藏网页上的广告、弹窗等干扰内容。新增一个网站只需要加一条规则。

- 生效页面：所有网站，具体隐藏只在规则命中的网站或路径上生效
- 隐藏的内容不占位置，也无法点击
- 不易触发网站的「检测到广告拦截器」提示
- 已内置的规则：
  - Forvo：弹窗、遮罩、推广横幅，以及占据大量空间的页头与导航
  - 全历史：会员推广弹窗
  - Photopea：右侧广告栏、新建项目窗口中的推广区、通知窗口

## 自定义规则

可以为任意网站补充要隐藏的内容，脚本更新后自定义规则仍然保留。

1. 打开 Tampermonkey 管理面板，进入本脚本的编辑页，切换到「存储」页。看不到该页时，先在 Tampermonkey 设置里把「配置模式」改为「高级」。
2. 编辑 `rules` 的值并保存。写法如下，键是生效范围，值是要隐藏的元素的 CSS 选择器：

```json
{
  "example.com": [".ad-banner", "#popup"],
  "example.com/docs": [".sidebar-sponsor"]
}
```

- `*`：所有网站
- `example.com`：该域名及其子域名
- `example.com/docs`：该域名下 `/docs` 及其下级页面
