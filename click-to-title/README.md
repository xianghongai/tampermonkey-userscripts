# Click to Title

有些单页应用切换页面时不更新标题，所有标签页都只显示应用名，难以区分。这个脚本可以把页面上的任意文字设为当前标签页的标题。

自用脚本，只放在仓库中，不发布到 Greasy Fork。

- 生效页面：所有网站
- 按住 Ctrl+Shift（macOS 为 ⌘+Shift）点击页面上的文字，例如页面标题、面包屑、菜单项，它就成为标签页标题，并附带原来的应用名，例如「订单详情 - 应用名」
- 每个页面地址各自记住设置的标题，在应用内来回切换时自动换上对应的标题
- 设置的标题只在当前标签页有效，刷新或关闭后恢复原样
- 触发按键、是否附带应用名可以修改：编辑脚本开头的配置，写法见其上方的注释
