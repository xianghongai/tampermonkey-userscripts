# AI Chat Tweaks

ChatGPT、Claude、Gemini、DeepSeek、通义千问、Grok 的对话区宽度、自己发出的消息的样式各不相同，在几个 AI 之间来回切换时，视线和阅读节奏总要重新适应。这个脚本把它们统一起来。

- 生效页面：ChatGPT、Claude、Gemini、DeepSeek、通义千问（chat.qwen.ai）、Grok 的对话页
- 对话区与底部输入框统一为同一宽度，默认为屏幕宽度的一半（`50vw`），两者等宽对齐
- 自己发出的消息统一为同样的气泡：饱和鲜亮的单色渐变底色叠一层细腻的磨砂噪点，配白色文字、同色柔和投影，气泡宽度统一为对话区宽度的 68% 并靠右，以及同样的圆角和内边距
- 渐变预设五组：紫罗兰、玫红、湛蓝、橙黄、青绿，在 Tampermonkey 菜单里选，当前选中的带 ✓，选完立即生效，默认紫罗兰
- AI 的回复，以及各站点自己的配色、深浅色主题保持不变
- 可在 Tampermonkey 菜单的「设置对话区宽度」中修改宽度，写成 CSS 长度，例如 `50vw`、`900px`；留空恢复默认
