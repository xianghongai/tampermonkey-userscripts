# Tampermonkey UserScripts

Tampermonkey userscripts made for my own use and shared publicly. See the README in each script's folder for usage (in Chinese). Published scripts can be installed from Greasy Fork.

- [AI Chat Quick Delete](ai-chat-quick-delete/): Delete a conversation from the sidebar of ChatGPT, Claude, Gemini, DeepSeek, Qwen and Grok in one click. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/601564-ai-chat-quick-delete)
- [AI Chat Tweaks](ai-chat-tweaks/): Give ChatGPT, Claude, Gemini, DeepSeek, Qwen and Grok the same conversation width and the same bubble style for your own messages. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/601563-ai-chat-tweaks)
- [BootCDN: Copy All](bootcdn-copy-all/): Copy the links or tags of all files on a BootCDN library page at once.
- [Copy Anyway](copy-anyway/): Copy text on pages that block selecting or copying, and stop sites from appending copyright notices.
- [Copy it 🚀](copy-it/): Alt+click any element to copy its text, or copy it in a common naming case. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/448222-copy-it)
- [Gist: Download Commands](gist-download-command/): Copy a command that downloads a file from a Gist page. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/601397-gist-download-commands)
- [GitHub 😍 DeepWiki](github-deepwiki/): Open a GitHub repository's DeepWiki docs in one click. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/600227-github-deepwiki)
- [GitHub & Gist: Collapse & Copy](github-gist-collapse-copy/): Collapse Gist files and GitHub comments, and copy their source in one click. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/600306-github-gist-collapse-copy)
- [GitHub & Gist: Mask Secrets](github-mask-secrets/): Mask tokens, passwords and other secrets in GitHub repos and Gists when sharing your screen or copying code. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/600550-github-gist-mask-secrets)
- [Nav Dashboard](nav-dashboard/): Lay out a documentation site's navigation groups on a full-screen board to see the whole tech stack. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/402459-nav-dashboard)
- [No-Translate Zones](no-translate-zones/): Keep code blocks and chosen content in the original language when translating a page. ![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/374163-no-translate-zones)

## 简体中文

自用并公开的 Tampermonkey 脚本，每个脚本的用法见各自目录下的 README。已发布的脚本可以从 Greasy Fork 安装。

- [AI Chat Quick Delete](ai-chat-quick-delete/)：在 ChatGPT、Claude、Gemini、DeepSeek、通义千问、Grok 的对话列表中一键删除对话。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/601564-ai-chat-quick-delete)
- [AI Chat Tweaks](ai-chat-tweaks/)：让 ChatGPT、Claude、Gemini、DeepSeek、通义千问、Grok 的对话区宽度一致，自己发出的消息统一为同一种气泡样式。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/601563-ai-chat-tweaks)
- [BootCDN: Copy All](bootcdn-copy-all/)：在 BootCDN 的库页面一次复制全部文件链接或标签。
- [Copy Anyway](copy-anyway/)：在禁止选择、复制的页面上照常复制文字，并阻止网站追加版权声明。
- [Copy it 🚀](copy-it/)：按住 Alt 点击任意元素复制其文字，还能复制成常用的变量命名风格。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/448222-copy-it)
- [Gist: Download Commands](gist-download-command/)：在 Gist 页面一键复制下载某个文件的命令。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/601397-gist-download-commands)
- [GitHub 😍 DeepWiki](github-deepwiki/)：在 GitHub 仓库页面一键打开该仓库在 DeepWiki 上的文档。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/600227-github-deepwiki)
- [GitHub & Gist: Collapse & Copy](github-gist-collapse-copy/)：折叠 Gist 文件与 GitHub 评论，并一键复制原文。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/600306-github-gist-collapse-copy)
- [GitHub & Gist: Mask Secrets](github-mask-secrets/)：共享屏幕或复制代码时遮盖 GitHub 仓库与 Gist 里的 Token、密码等凭据。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/600550-github-gist-mask-secrets)
- [Nav Dashboard](nav-dashboard/)：把技术文档网站的导航分组铺开成全屏看板，一览整个技术栈。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/402459-nav-dashboard)
- [No-Translate Zones](no-translate-zones/)：翻译网页时保留代码块及指定内容的原文。![Greasy Fork](assets/greasyfork.svg) [Greasy Fork](https://greasyfork.org/scripts/374163-no-translate-zones)
