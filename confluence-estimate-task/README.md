# Confluence 'Estimate & Task'

Confluence 工时评估与任务分解：汇总表格中「工时」列的总和，并一键复制 WBS 任务列表。

- 生效页面：域名以 `jira.` 开头的 Confluence 页面
- 页面右下角出现两个图标：「汇总评估工时」和「WBS」
- 「汇总评估工时」把「工时」列的数值相加
  - 只有一个表格时，总工时复制到剪贴板
  - 有多个表格时，页面上分别列出每个表格的总工时
  - 编辑模式下，总工时写入表格最后一行的「工时」单元格
- 「WBS」把「工时」列左边的各列整理成每行一条的文字，各列之间用「 - 」连接，表格中合并的单元格沿用上一行的内容；结果显示在页面上，并复制到剪贴板

## 使用前提

- 表格需要有名为「工时」的列，工时写成「3d」「0.5d」这样的格式
- 页面地址不是 `jira.` 开头时，需要把 `@match` 改成自己的 Confluence 地址
