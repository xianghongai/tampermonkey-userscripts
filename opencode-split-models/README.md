# OpenCode: Split Models

把 OpenCode 控制台的 Models 页面分成两个列表：已启用的模型在上，未启用的在下；开关模型后自动移到对应的列表。

- 生效页面：OpenCode 控制台的 Models 页面
- 两个列表各有一行标题，括号里是该组的模型数量
- 每组内按模型名称排序
- 点击 Input、Output、Cache Read、Cache Write 表头，两个列表各自按该列价格排序：第一次点击升序，第二次降序，第三次恢复按名称排序；没有价格（显示为 `-`）的模型排在最后
- 工具栏的 Model actions 按钮旁有一个分组开关，默认开启。关闭后两个列表合并为一个，全部模型按当前排序显示，方便不分可用状态直接比较价格；开关状态会记住
- 搜索模型时，两个列表只显示匹配的结果
