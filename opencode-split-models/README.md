# OpenCode: Split Models

把 OpenCode 控制台的 Models 页面分成两个列表：已启用的模型在上，未启用的在下；开关模型后自动移到对应的列表。

- 生效页面：OpenCode 控制台的 Models 页面
- 两个列表各有一行标题，括号里是该组的模型数量
- 每组内的顺序与页面一致（默认按名称），移动后的模型留在它在页面中的位置
- 页面自带的表头排序可以直接使用：点 Input、Output 等表头后，两个列表同时按该列排序
- 工具栏的 Model actions 按钮旁有一个分组开关，默认开启。关闭后两个列表合并为一个，全部模型按页面当前的顺序显示，方便不分可用状态直接比较价格；开关状态会记住
- 搜索模型时，两个列表只显示匹配的结果
