# Google Contacts: Shortcuts

在 Google 通讯录里用键盘进入编辑、保存修改，不用来回移动鼠标找按钮。

自用脚本，只放在仓库中，不发布到 Greasy Fork。

- 生效页面：Google 通讯录（`contacts.google.com`）
- 打开联系人后，按 Alt+L 进入编辑
- 编辑时按 Alt+O 或 Ctrl+S（macOS 为 ⌘+S）保存
- 当前页面没有对应按钮时，按键保持原有作用
- 快捷键可以修改：编辑脚本开头的 `SHORTCUTS`，写法见其上方的注释
- Google 更新页面后快捷键可能失效，这时更新脚本开头 `BUTTONS` 中按钮的选择器
